# LP レイアウト・縦リズム・Our name 濃色帯 — 設計

日付: 2026-08-11
対象: `index.html` / `style.css`

## 背景

デスクトップ幅（1512px）で通して見たときの問題:

1. **横幅が使われていない。** `--wrap: 820px` の中央寄せ1カラムのため、ワイド画面では左右に大きな余白が残り、ページ全体が「文書」に見える。視線の起点がない。
2. **縦の余白が大きすぎる。** `.section` の上下パディングが最大 120px。隣接セクション間で 240px が空き、スクロールが間延びする。
3. **「Our name」が埋もれている。** kokkara → "Life starts from here." はページの心臓部だが、他セクションと同じ本文サイズ・同じ淡い tint 背景で、素通りされる。

あわせてモバイル表示の見やすさを確認・改善する。

## 検討したが採らなかった案: 言語別の背景色

英語版の背景をネイビー、日本語版を白にする案を検討したが、採用しない。

- 英語ページの読者は豪州人に限らない。国旗色で言語を表すと「英語圏＝オーストラリア」という成り立たない等式になる。
- CoColour の中核は「Co＝共に」。言語で見た目を分断すると、日豪をつなぐというメッセージと逆を向く。
- 実質ダークモードを1本追加することになり、本文色・リンク色・カード・tint 帯・フォーカスリングの再設計とコントラスト再検証が必要。保守対象が倍になる。
- ロゴのドットリング内の `#BC002D`（style.css 上で "the Japan sun" と注記）が既に日豪を表現している。

代わりに「濃い色で締めたい」という意図を、課題3の解決と統合する（下記③）。

## 方針

HTML の要素構造は変更しない（`#name` の class 属性1箇所のみ差し替える）。実質的に `style.css` だけで対応する。新しい依存・ビルド工程は追加しない。`script.js`（scrollspy・言語切替）は変更しない。

## ① 横幅を使う — 2カラムの編集レイアウト

- `--wrap` を `820px` → `1080px`。
- `.section > .wrap` を Grid 化する:
  - `grid-template-columns: 260px minmax(0, 1fr)`
  - `.section-title` → 1列目・全行スパン・`position: sticky`
  - `.section > .wrap > *:not(.section-title)` → 2列目
- Grid 化は `.section > .wrap` にセレクタを限定する。ヘッダー（`.header-inner`、flex）・フッター・Hero（`.hero-inner`）には適用しない。
- 900px 未満では 1カラムに戻し、現状と同じ縦積みにする。

`--wrap` の拡大はヘッダーとフッターにも及ぶ（本文と左端が揃うため望ましい）。

## ② 縦のリズム

| 対象 | 現在 | 変更後 |
|---|---|---|
| `.section` 上下（デスクトップ） | 120px | 80px |
| `.hero` 上下（デスクトップ） | 144px | 104px |
| `.section` 上下（モバイル） | 56px | 44px |

`clamp()` の値を調整して実現する。`.areas` のカード間 `gap` は変更しない。

## ③ Our name — ディープティールの濃色帯

- `#name` のクラスを `section--tint` → `section--deep` に変更（HTML の class 属性1箇所のみ変更）。
- 背景 `#1a5f56`、文字は白。
- 見出し下のグラデーション罫（現在 teal→blue→amber→terracotta）は濃色地では teal が沈むため、ロゴのパステル色に振り替える。
- `.dot-divider` も濃色地で読める配色に調整する。装飾のみ（`aria-hidden`）だがコントラストは確認する。
- `.name-coda` をページ最大の文字にする: 現在 `clamp(1.3rem, 1.12rem + 0.9vw, 1.6rem)` → `clamp(2.2rem, 1.8rem + 1.6vw, 3rem)` 程度。
- `.section-title::before` のマスク色（`--marker`）を濃色地用の明色にする。

結果として背景は Hero（淡いグラデ）→ About（白）→ **Our name（濃いティール）** → Activities（白）→ Founder（白）→ Contact（淡い tint）→ Privacy（白）と流れ、Our name がページ前半の視覚的な中心になる。

### コントラスト要件

- 白 `#ffffff` / `#1a5f56` は 4.5:1 以上（AA）を満たすこと。実装時に実測して確認する。
- 濃色帯内の副次テキスト（`.name-coda-intro`）も 4.5:1 以上を満たすこと。

## モバイル

390px / 768px / 1440px の3幅でブラウザ実表示を確認し、以下を修正する:

- Hero のロゴマーク（560px 以下で 86px・右下配置）とタグラインの重なり
- ヘッダー（ワードマーク＋言語トグル）の収まり — 390px で折り返さないこと
- 濃色帯の全幅表示と `.name-coda` の文字サイズ
- `.areas li` の内側余白とタップ領域
- 日本語版の行長・改行位置

`.site-nav` を 767px 以下で非表示にする現在の挙動は変更しない（6セクションの単一ページであり、スクロールで足りる）。

## 検証

- 濃色帯の文字色コントラストを実測し、AA（4.5:1）を満たすことを確認する。
- キーボードフォーカス（skip link、nav、言語トグル、リンク）が濃色帯上でも見えることを確認する。
