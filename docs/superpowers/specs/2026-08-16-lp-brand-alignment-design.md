**設計原則（本LPの拘束条件）**

> 白地でAA本文を通るのは **Navy と Crimson の2色のみ**。パステル6色は白地では大文字AAすら通らない。
> したがって — **Navy＝文字 / パステル＝地・装飾 / 白＝ネイビー地上の反転文字**。

これはブランドブック自身のページ構成（p.2〜p.15 が全面パステル地＋白/Navy文字）とも一致する。なおブランドブック p.11 は白地に Mint `#8FC9BB` で本文を組んでおり（1.87:1）自ら原則を破っているが、**これは模倣しない**。

**ブランドブックの誤記（デザイナー差し戻し事項、本LPには影響なし）**: p.9 で `#83BED1` の RGB が `143/201/187` と印字されている。これは隣の `#8FC9BB` からのコピペミス。正しくは 131/190/209。HEXラベル側が正しい（レンダリング実測 `#83BDD1`、JPEG量子化 `#84BED2` で裏取り済み）。10色中この1件のみ。

### 2.4 タイポグラフィ

`BRAND BOOK.pdf` に実際に埋め込まれているフォント（サブセットプレフィクス除去後、全19ページ走査）:

| 書体 | 出現 | 役割 |
|---|---|---|
| Poppins-SemiBold | 全ページ | 見出し。事実上の主要書体 |
| Poppins-Regular | p.2–15 | 本文 |
| NotoSansJP-Thin | p.1–14 | 和文サンプル |
| Montserrat-Regular / Bold | p.2, p.15 | 目次・パターンページ |
| AmazonEmber-Medium | **p.11, p.12 のみ** | 書体見本の「Aa」とアプリアイコン |

p.11 の指定は `Amazon Ember Medium` ＋ `Noto Sans JP SemiBold`。しかし:

- **Amazon Ember は Dalton Maag が Amazon 専用に制作した専有書体で、第三者はライセンス取得不可**。同梱の `Fonts/Amazon Ember Medium.ttf` の name テーブルに `This font may not be altered in any way without prior permission of Dalton Maag Ltd.` とあり、再配布も不可
- ブランドブック本体は Amazon Ember で組まれていない（実体は Poppins）
- 和文見本は「SemiBold」とラベルされているが実際は Thin（Weight 100）でレンダリングされている

→ **LPの書体は変更しない。** 現行の Source Sans 3 + Noto Sans JP を維持する。上記3点はデザイナーへの差し戻し事項とする。

## 3. 決定事項

| 論点 | 決定 |
|---|---|
| スコープ | ロゴ＋配色・書体のブランド準拠。LPの構造・文言・情報設計は変更しない |
| 本文の文字色 | **現行維持**（`--ink: #2a2c33`）。長文の可読性優先 |
| 見出し・濃色帯・リンク | **ブランドネイビー `#1B1464`** |
| ティール／テラコッタ | **全廃**。ネイビー＋クリムゾン＋公式パステルに置換 |
| 架空グリフ（弧＋点） | **全廃** |
| 見出し前のマーク | **クリムゾンの点のみ**（11px の円） |
| 書体 | 変更なし |
| 公開 | ローカル確認 → 承認 → `main` に push。`noindex` は維持 |

### 3.1 見出しマークをリングにしなかった理由

実寸20pxで5案を比較検討した（12ドットのリング / 8ドット＋アクセント / 6ドットの開いた弧 / 点のみ / なし）。

1. **物理的制約** — 本物のマークは39ドット。20pxではどの簡略版でも輪郭が潰れ、「読み込み中のスピナー」に見える
2. **ブランド原則** — 納品物レポート D-5 で、ブランドパターンがロゴを敷き詰めていることを「ロゴ改変禁止と自己矛盾」と指摘した。見出しごとに小さなロゴもどきを置くのは同じ問題を犯す

クリムゾンの点はロゴの署名要素の引用であり、マークの模倣ではない。どのサイズでも潰れない。

- 背景ブロブ3つ — Peach / Periwinkle / Butter。パステルは彩度が低いので opacity を 0.05–0.07 から 0.16–0.22 に上げる

### 4.3 グリフ

**見出し前のマーク** — `.section-title::before` からマスクを外し、11px の円 `background: var(--dot)` に。`--dot: var(--crimson)`、`.section--deep` では `#ffffff`。`--co-glyph` トークンは全廃。

**カードの透かし** — `--motif-*` 4種を、円だけで構成した図に差し替える。ドットはブランドの造形言語なので、ロゴを模倣せずにブランドの語彙で話せる。

| カード | 図 |
|---|---|
| 研究・評価 | 4つの点が右上がりに大きくなる（データ系列） |
| 教育・知識の実装と普及 | 大きい点から3つの小さい点が右に広がる |
| アドバイザリー・協働 | 同じ大きさの点2つと、上に小さい点1つ |
| 日豪連携 | 両端の大きい点2つを、小さい点3つが橋渡し |

描画色は `--card-accent`（パステル）ではなく `--navy` の opacity 0.30。パステルはクール地の上で沈んで見えないため。

**フッター** — インラインの架空SVG（緑の弧＋テラコッタの点）を `<img src="assets/logo-mark.svg">` に置換。`.footer-mark svg` セレクタを `.footer-mark img` に変更し、`width: 42px; height: auto`（マークは正方形でなく 1.0285:1 のため縦を追従させる）。

### 4.4 印刷スタイル

`.section--deep` は印刷で地色を失うため、白の下線と白の点が消える。`--marker` に加えて `--dot: #000 !important` を追加する。
